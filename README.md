# Sistema de Gestión "Casa del Constructor" 

Aplicación de escritorio desarrollada para la gestión eficiente de inventarios, ventas y control de clientes en una ferretería. 

## Tecnologías Utilizadas
* **Lenguaje:** Java
* **Interfaz Gráfica:** Java Swing con diseño FlatLaf
* **Base de Datos:** MySQL
* **Arquitectura:** Conexión mediante JDBC y flujos de Service Desk.

## Características Principales
* Registro y administración ágil de clientes y proveedores.
* Control de stock y manejo de inventarios en tiempo real.
* Procesamiento de transacciones y registro de ventas.
* Interfaz gráfica moderna, fluida y orientada al usuario.
